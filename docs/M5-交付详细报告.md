### 2.2 新增包：`internal/webui`（F2 的核心）

这是 M5 唯一的生产代码新增包，4 个源文件 + 3 个测试文件。挂载点用
`r.NotFound(...)` 而非 `r.Handle("/*")` —— chi 的 `NotFound` 只在**所有已注册路由
都没命中**时触发，天然满足「`/api/*` 与 `/healthz` 先于静态兜底」，
且不与既有 `r.Get("/api/v1/incidents/{id}")` 之类参数路由抢匹配。

| 要点 | 实现 | 踩过的坑 |
|------|------|---------|
| 开关 | `IIP_WEB_ROOT` 空 → `Handler()` 返回 `nil` → **完全不注册**。不设时行为与 M4 逐字节一致 | — |
| 路由优先级 | `r.NotFound(h.ServeHTTP)`，注册在所有 API 之后 | — |
| SPA 回退 | 未命中且非 `/api/` → 返回 `index.html` | — |
| 路径逃逸 | `safeRel` 逐段判 `..`（**不**用整串 `strings.Contains`）+ 拒反斜杠 + `withinRoot` 用 `filepath.Rel` 二次校验 | — |
| 缓存 | `assets/` 前缀 → `public, max-age=31536000, immutable`；其余 `no-cache` | — |
| Content-Type | 显式扩展名表 | **不用 `mime.TypeByExtension`**：它读宿主 `/etc/mime.types` 与注册表，distroless 里两者都没有 → 返回空串 → 浏览器拒绝执行脚本 |
| go:embed | **确认不用** | dist 走 compose 挂载 |

### 2.3 迁移：零新增

M5 全程**未新增任何迁移**。静态托管的 dist 走 compose 挂载而非烧进镜像，
这是 M5 相对 M0–M4 的一处形态变化（也与 ADR-005 的多阶段构建不冲突）。

## 4. 过程中发现并修复的实现缺陷

### 4.1 产品缺陷（一处）

**`serveIndex` 的文件句柄从未关闭**。原用 `ServeContent` + 自建 reader，
句柄没关 → `t.TempDir()` 在测试末尾删不掉目录。

> **判据：测试末尾出现 TempDir cleanup 失败，先查有没有未关闭的句柄，别急着 `t.Skip`。**
> 这条与「测试红了」的方向相反 —— 产品有 bug，但症状出现在测试的清理阶段。

### 4.2 三条测试写错而非产品缺陷

写下来是因为它们**看起来都像产品坏了**：

1. **`os.Symlink` 在无管理员权限的 Windows 上返回 nil 却建不出有效链接**
   （缺 `SeCreateSymbolicLink`），导致「root 是符号链接」这条路径长期 SKIP。
   已用 `os.Stat` 验链接有效性后 `t.Skip`，并**另写一条**
   `TestHandlerAcceptsNonCanonicalRoot` 覆盖「root 路径带冗余段与 `..` 但经 Clean 后合法」
   这一可验证的部分。真实 symlink 形态**须在容器链路（Linux）补验** → **OPEN-M5-6**。
2. **`httptest.NewRequest` 遇反斜杠（`\..\SECRET.txt`）直接 panic**
   （`invalid URI for request`）。已另写 `doRaw` 用 `&url.URL{Path: p}` 手工构造
   —— **恰恰是这种非法输入最需要测**，不能因为构造工具嫌它非法就跳过。
3. **断言 `/v1.0..next/index.html` 期望 200，实得 301**。**301 是正确行为**：
   `http.ServeFile` 对以 `/index.html` 结尾的 URL 会规范化重定向到 `./`。
   改成测 `/v1.0..next/data.json`。**把标准库的既定行为记成产品 bug 是这类测试的典型错法。**

### 4.3 F8 的 4 条红全是测试写错

F8 真跑 `e2e-06-cfg-evidence.spec.ts` 时 4 条红，逐条查证后**全部是测试写错，
产品零缺陷**，四处已写入用例注释。

### 4.4 两处「假通过」的记录（M5 期间自查发现）

- **判据 11 曾据 `docker ps` rc=0 说「daemon 已恢复」，是错的**：
  半锁死时只读命令本就全部 rc=0 且秒回。
  真跑第二次容器链路（13 个本地镜像齐备、无需 pull），停在构建阶段
  **19 分 21 秒无产出**，定因为 `vmmemWSL` 20 秒 CPU 增量 0 + `Created` 僵尸 2→9。
  **判据 4/11/13 的容器侧仍记「未跑成」，没有一项算通过。**

## 5. 前端（明暗主题与视觉，ADR-021）

| 项 | 内容 |
|---|---|
| 主题 | 明暗双主题，ADR-021 记录「深色专业控制台」基调；`709ac8e` |
| 令牌化 | 颜色统一走 `themeVars.ts` 注入的 CSS 变量，**不硬编码** |
| 暗色值陷阱 | `index.css` 写死暗色值会在切亮色时留黑块 —— 由像素断言抓出 |
| 语义色对比度 | `#0071f3` 在 `#eaeef2` 上仅 **3.87:1** → 压到 `#0060c0` |
| antd 行高亮 | 行背景色设在 `td` 不在 `tr` → 行级高亮写 `> td:first-child` 的 inset box-shadow。**单测抓不到，只有真渲染能验** |
| 只有真渲染能验的三类 | hover / 焦点 / 主题切换。jsdom 无布局无 hover → Playwright + 系统 Chrome（`channel:'chrome'`，本机装不了自带 chromium） |
| 像素断言 | 截图颜色种类 ≥4（纯白/纯黑失败页只有 1 种）。判据 4 实测 **1198 种** |

**判据落「属性语义」而非字符串形态**：hover 前 `box-shadow` 是
`rgba(0,0,0,0) 2px 0px 0px 0px inset`，用 `!=='none'` 会假红。
复位判据用**卡片底色**（暗 `rgb(22,27,34)` / 亮 `rgb(246,248,250)`），
**不能用 documentElement**。
